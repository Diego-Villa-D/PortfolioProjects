# Chicago Crime Visualization

## Overview

This project visualizes crime patterns across Chicago using an interactive map. Each point represents a **Chicago community area**, allowing users to quickly identify crime hotspots throughout the city.
https://diego-villa-d.github.io/DataAnalyticsPortfolio/DataViz/CHICAGO/mapa_crimenes_chicago.html

## Features

- Interactive scatter plot over a map of Chicago.
- Point size is proportional to the number of reported crimes.
- Point color represents crime intensity (darker red = more crimes).
- Dropdown menu to filter by any available **crime type (`primary_type`)**.

## Technologies

- Python
- Plotly
- Pandas

## Dataset

- Chicago Crime Dataset
- Aggregated by **community area** and **primary crime type**.

## Visualization

- **Location:** Community Area
- **Size:** Number of crimes
- **Color:** Crime intensity
- **Filter:** Crime type (`primary_type`)

## Objective

Provide an intuitive visualization that helps identify spatial crime patterns and compare the distribution of different crime types across Chicago.
